# RULES
- Before we start planning or implementation, read the `session_context.md`, so that you have full context of the codebase.

- If `session_context.md` is missing or stale, ask the user to provide it before proceeding.

- Don't run 'npm run build' everytime you make a changes of the codebase, this will waste time and resources.

- Don't run the browser to see the output, the user will manually check the output.

- Do not assume the state of the codebase from prior sessions — always verify from context.

- Do not use Emojis as icons, use libraries (eg. Lucide icons).
